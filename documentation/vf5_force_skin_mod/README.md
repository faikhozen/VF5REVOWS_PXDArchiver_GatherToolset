# VF5 Force Skin Mod Documentation

This folder contains documentation and resources for forcing / overriding character skins and costume models in **Virtua Fighter 5 R.E.V.O.**.

## 📑 Documentation Index

- [Tops Character & GMD Audit](TOPS_CHARACTER_GMD_AUDIT.md) — Complete inventory of all 190 subfolders and `.gmd` mesh files extracted from `chara.par.unpack/tops`, categorized per character slot (Akira, Sarah, Lau, Shun, Jeffry, Pai, Jacky, Kage, Lion, Wolf, Aoi, Lei-Fei, Vanessa, Brad, Goh, Eileen, El Blaze, Jean, Taka-Arashi, Dural, TST).
- [vf5item `*_JO_OUT_*.gmd` Mesh Audit](VF5ITEM_JO_OUT_GMD_AUDIT.md) — Detailed inventory and taxonomy of all 81 upper body outerwear (`JO_OUT`) mesh files across 19 roster characters from `chara.par.unpack/vf5item`.
- [Master Bone Rig (`chara.par.unpack/bone`) Audit](MASTER_BONE_GMD_AUDIT.md) — Comprehensive inventory and taxonomy of the 21 selected primary roster master bone files (`c_v00_VF5_*` to `c_v20_VF5_*`).
- [`vf5revows_dummy_gmds` Framework Documentation](VF5REVOWS_DUMMY_GMDS_DOCUMENTATION.md) — Complete guide, technical methodology, and repository inventory for the 21 character-specific dummy `.gmd` templates used to create 0-geometry blank meshes while preserving 100% of skeleton armature bones.
- [Mod Compiler Option 3: Master Skin Mod Specification](MASTER_SKIN_MOD_SPECIFICATION.md) — Complete architectural specification, 3-stage compilation pipeline, and character replacement taxonomy for compiling Master Skin Mods.
