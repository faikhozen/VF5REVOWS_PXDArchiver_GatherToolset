## 🔍 Technical Observations & Modding Insights

1. **Anatomy of `vf5item` vs `tops`:**
   - `chara.par.unpack/tops`: Contains complete costume packages, base character meshes (`c_v00-v98`), and physics files (`.hn2v`).
   - `chara.par.unpack/vf5item`: Contains modular customizable item meshes categorized by body attachment slots (`JO` Upper Body, `KA` Lower Body, `AT` Head, `FA` Face accessories, `TE` Hands/Gloves, `ASI` Shoes/Boots).
2. **`JO_OUT` Slot Functionality:**
   - `JO_OUT` represents upper body outerwear (jackets, coats, capes, open shirts, outer armor layer).
   - Outerwear meshes attach over `JO_INN` (Innerwear / Base shirts) or directly onto base upper body node structures.
3. **Universal Coverage:**
   - `JO_OUT_04` (`ITM033`) is present for **all 19 roster characters**, making `ITM033` the safest standard baseline slot for upper outerwear mods.
4. **Unique Outliers:**
   - **Sarah (`SAR`):** Only has 2 `JO_OUT` files (`SAR023` / `_03` and `SAR033` / `_04`), as most of her upper body items are classified under `JO_INN` or full tops.
   - **El Blaze (`MON` / `MON1000`):** Features a unique 6th slot `MON1000_JO_OUT_06.gmd` (24,576 bytes / 24 KB).
5. **File Packaging Integrity:**
   - Every `*_JO_OUT_*.gmd` file resides inside its dedicated item subfolder without secondary texture or configuration files, confirming that `.gmd` model definitions in `vf5item` link externally to shared texture archives.
