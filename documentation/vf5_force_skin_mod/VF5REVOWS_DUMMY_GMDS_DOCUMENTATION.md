## 📊 Executive Summary Overview

The `vf5revows_dummy_gmds` set is a curated collection of **21 character-specific master dummy `.gmd` templates** for Virtua Fighter 5 R.E.V.O. force-skin and costume modding.

Each dummy `.gmd` file corresponds to one of the 21 character slots (`v00` through `v20`). When replacing any item or costume mesh `.gmd` file in `vf5item` or `tops`, it accomplishes two key objectives:
1. **Complete Geometry Blanking (0 Faces / 0 Triangles):** Forces the game engine to render zero 3D mesh geometry, making unwanted clothes, jackets, accessories, hair, or armor completely invisible.
2. **100% Skeleton & Armature Node Preservation:** Retains all character skeleton nodes, joint transform matrices, and physics attachment anchors, preventing crashes, T-poses, or missing bone attachment errors.

## ⚙️ Technical Methodology & Why It Works

### 1. The GMD Binary Architecture Issue
Manual binary zeroing of vertex buffers or header offsets can cause parsing crashes in Blender or Virtua Fighter 5 due to:
- **Shift-JIS Texture Array Corruption:** Missing or zeroed texture array string pointers (`texture_arr`).
- **Shader & Vertex Layout Mismatches:** Disconnecting submesh shader indices (`+0x2C`) from Bytes-Per-Vertex (BPV) layout tables (`+0x04`).

### 2. The Master Bone Solution
Official Sega master bone files (`c_vXX_VF5_<CHAR>_bone.gmd`) are natively structured with:
- `submesh_count = 0` (0 3D geometry / 0 draw calls).
- `material_count = 0`.
- **Full Character Skeleton Node Array (`GSGM!` format)**.

By replacing any item `.gmd` file with its character's master bone template, the game engine and Blender GMD Importer process a **100% valid game-original `.gmd` structure**, achieving perfect blanking with 0 errors.

## 🔄 Batch Automation & Character Matching Rules

To blank out items recursively across `vf5item` and `tops`:
1. **Scan Subdirectories:** Recurse through `vf5item` and `tops` in an unpacked `.par` archive.
2. **Match Character Code:** Extract the 3-letter character code from directory paths or filenames (e.g. `AKI` for Akira, `SAR` for Sarah, `MON` for El Blaze).
3. **Copy & Overwrite:** Copy the corresponding template file from `vf5revows_dummy_gmds` and overwrite the target `.gmd` file (retaining the target's original filename).
